# Guía de Aprendizaje del Proyecto

Este directorio agrupa notas en formato Markdown para ayudarte a entender cómo está construido el blog técnico dentro de `src/`. Cada documento se enfoca en un aspecto específico: manejo de estado global, componentes de interfaz, animaciones y flujos de datos.

## Rutas sugeridas

- **`arquitectura-general.md`** — Visión panorámica del blog, principales dependencias y flujo de datos.
- **`contexto-blog.md`** — Explica el `BlogProvider`, el reducer y las acciones disponibles.
- **`componentes-clave.md`** — Desglosa componentes como `TechBlog`, `BlogPost`, `BlogEditor` y `CascadeBackground`.
- **`animaciones-y-ui.md`** — Documenta el uso de Framer Motion, Intersection Observer y estilos Tailwind.
- **`estado-y-filtrado.md`** — Describe cómo se manejan filtros, búsqueda, ordenamiento y paginación.

Cada archivo incluye referencias directas a rutas de código (`src/`) y fragmentos relevantes para que puedas orientarte rápidamente.
