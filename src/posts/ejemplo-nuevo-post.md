# Ejemplo: Cómo Crear un Nuevo Post

Este es un ejemplo de cómo estructurar un nuevo post en Markdown.

## Sección 1

Puedes escribir contenido normal aquí. El formato Markdown te permite usar **negritas**, *cursivas*, y más.

### Subsección

También puedes crear listas:

- Item 1
- Item 2
- Item 3

## Código

Puedes incluir código inline: `const ejemplo = "código"`

O bloques de código:

```javascript
function ejemplo() {
  return "Hola mundo";
}
```

## Conclusión

¡Eso es todo! Solo crea un archivo `.md` en la carpeta `src/posts/` y sigue esta estructura.
